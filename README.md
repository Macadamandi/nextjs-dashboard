# Next.js Dashboard

This project was created as part of my practice with **Next.js** and the **Next.js App Router**.

The application is based on the official Next.js Dashboard tutorial and was developed as a learning project to practice building a modern full-stack web application with Next.js.

## About the Project

The project is a dashboard application that demonstrates different Next.js features and concepts, including:

* Next.js App Router
* Server and Client Components
* Routing and layouts
* Data fetching
* PostgreSQL database integration
* Supabase
* Authentication with Auth.js
* Form handling and validation
* Search and pagination
* Loading states and Suspense
* Responsive UI
* TypeScript
* Tailwind CSS

The project was built for educational purposes to gain practical experience with Next.js and its ecosystem.
